# Johnson & Johnson - Robotics and Controls

This folder contains the work for the Johnson & Johnson Forage job simulation.
Each task has its own folder so that the supplied materials, working notes,
code, tests, and final deliverables remain separate.

## Tasks

- [Task 1 - Introduction to control systems and diagnostics](task-1-control-systems-and-diagnostics/README.md)

## Repository conventions

- `references/` contains materials supplied by Forage.
- `src/` contains implementation code when a task provides or requires it.
- `tests/` contains diagnostic or regression tests.
- `notes.md` is the learner's working notebook.
- `deliverables/` contains only submission-ready work.
